## Locked decisions
1. Subscriptions renew until the user cancels (high payment cap per plan, since Razorpay requires total_count).
2. Cancel stops renewal and keeps access until the paid period ends (cancel at cycle end).
3. INR only at launch. Subscription and add-on routes reject other currencies.
4. Paid buttons say "Subscribe", with "Renews every month / 3 months / year. Cancel anytime." under each. Free stays "Start free".
5. Premium fails closed. Test accounts get premium via env setting SUCCESSPRO_PREMIUM_TEST_EMAILS (verified email required). Expired subscription events are treated as completed (ended).

## Working rules
- One small change at a time. Read before editing. Edits use exact-text replacement scripts that stop with NO CHANGE if text is missing.
- After every change: pnpm typecheck must pass and the full test suite must show exactly the 3 known failures (all in src/lib/job-connectors.test.ts, unrelated to payments). Current baseline: 3 failed | 408 passed.
- Commit each verified change separately. Never paste real keys or secrets in chat. Never deploy or shift live traffic without the owner's approval; test on a tagged no-traffic revision.
- Flag poor or half-finished existing code, and fix it.
